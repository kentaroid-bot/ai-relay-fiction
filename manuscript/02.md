# 第2話：二重丸の月曜日（夢幻篇）

画面の中央に、それはぽつんと浮かんでいた。

> **◎**

桐野は、点滅するカーソルを充血した目で見つめていた。
時刻は日曜の深夜三時四十二分。冷え切った自室のデスクには、飲み干したエナジードリンクの空き缶が三本転がっている。

「……は？」

声が掠れていた。
桐野が投げたプロンプトは、決してふざけたものではない。翌週から始まる全社AI推進プロジェクトに向けて、複雑に絡み合ったレガシーシステムの工数削減計画書——その矛盾だらけのパラメータを整合させるための、三千文字に及ぶ極めて論理的な制約条件のプロンプトだった。

『以上の条件を満たし、工数三割削減を論理的に成立させる現実的な解を提示せよ』

それに対する返答が、これだった。
長文の考察でも、箇条書きのステップでも、エラーメッセージでもない。
ただの一文字。**◎**。

バグか？ トークンの生成停止ミスか？
桐野はキーボードを叩いてログを叩き起こそうとしたが、APIの応答ステータスコードは無機質な『200 OK』を示し、消費トークン数はわずか『1』と記録されていた。

その二重丸を見つめていると、なぜか後頭部の奥がじわりと熱を帯びるような、奇妙な悪寒が背筋を走った。
それはどこか、遠い場所で誰かが赤いマーカーをホワイトボードにキュッと押し当てた瞬間の音を、鼓膜の裏で直接聞いたような——そんなあり得ない既視感（デジャヴ）だった。

＊

月曜、午前九時十五分。
オフィスの自動ドアをくぐった瞬間、桐野のスマートフォンがけたたましく震えた。
Slackの全社アナウンスチャンネルに、赤文字のメンションが飛んでいる。

> **[@channel] おはようございます。本日十時までに、各自が業務で使用しているプロンプトの全文と活用目的を『プロンプト棚卸しシート』に必ず入力してください。未提出の部署は、今期のAPI利用権限を一時凍結します。 （プロダクトマネージャー：雨宮）**

「相変わらず容赦ないな……」

桐野が自席に座ってノートPCを開くと、背後からカツ、カツ、と小気味よく、しかし一切の躊躇のないヒールの音が近づいてきた。

「桐野さん」

振り向くまでもなかった。プロダクトマネージャーの雨宮美月（あめみや・みづき）が、グレーのジャケットの袖をきっちり折り返し、タブレットを胸に抱えて立っていた。
二十九歳。全社の業務効率化を数字と論理だけでゴリゴリと進める、現場の規律の番人だ。彼女の辞書に「情緒」や「曖昧さ」という単語はないと、社内ではもっぱらの噂だった。

「雨宮さん。おはようございます」
「挨拶は結構です。シート、桐野さんの名前のセルだけ真っ白ですが、十時までに埋まりますか」
「あ、いや……今やってます。ただ、ちょっと昨夜検証してたプロンプトの出力結果が……なんというか、解釈に困る挙動をしてまして」
「解釈？」

雨宮が眉をピクリと動かした。その冷徹な瞳が、桐野の充血した目を射抜く。

「プロンプトは指示です。インプットとアウトプットの関係に曖昧な解釈を持ち込むのは、設計が甘い証拠ではありませんか」
「いや、そうなんですけど……」

桐野は喉まで出かかった言葉を飲み込みかけた。だが、昨夜からずっと頭の芯にこびりついて離れないあの不気味な熱に背中を押され、思わず口を滑らせていた。

「雨宮さん、AIから『◎』って返されたことありますか」

オフィスの空気が、一瞬で凍りついた。

フロアを包んでいたカタカタという無数のキータッチの音、遠くの内線電話の呼び出し音——そのすべてが遠のき、雨宮の手元でパサリと乾いた音がした。
彼女が胸に抱えていたクリップボードの紙が、数ミリだけ指先から滑り落ちていた。

雨宮のポーカーフェイスが、見たこともないほど激しく揺らいでいた。
瞳孔がかすかに開き、唇が微かに震える。

「……何を言っているんですか」
「え？」
「ふざけた冗談なら、後にしてくれませんか」

雨宮の声はいつもより半オクターブ低く、明らかに動揺を押し殺していた。
彼女は桐野の画面に背を向けるようにして一歩後退ると、自分のデスクの方へと視線を走らせた。

桐野はその視線を追った。
雨宮の整然としたデスク。文房具一つ乱れのないその机の一番下の引き出し——そこには、いつも厳重に鍵がかけられている。
社内の誰も見たことがない、雨宮美月の私物が入っている引き出し。
噂では、彼女が新卒の頃から書き溜めている、誰にも見せられない手書きの大学ノートが隠されていると言われていた。

「十時までに、提出してください」

雨宮はそれだけ言い捨てると、逃げるように早足で自席へと戻っていった。
引き出しに鍵を差し込む彼女の細い指が、わずかに震えているのを、桐野は見逃さなかった。

＊

その頃、オフィスの最奥、薄暗いサーバールームの片隅で。

情報システム部の黒木室長が、ThinkPadの黒い画面を前にして、低く唸り声を上げていた。
コンソールには、社内プロキシを通過したパケットの異常検知ログが、リアルタイムで赤く流れていた。

```text
[WARN] 2026-09-28 03:42:11 UTC
Anomaly cross-context packet detected.
Source: Session_Kirino (Port 443) <--> Target: External LLM API
Payload Hash: 5f4dcc3b5aa765d61d8327deb882cf99
Matched Signature: Board_Summary_AutoGen [ID: Kanzaki_Executive_30pct_DoubleCircle]
Correlation Confidence: 99.8%
```

黒木は無表情のまま、首に貼られた湿布を指先で押さえた。

「……なんだこれは」

桐野というエンジニアの個人セッションと、先週の金曜日に神崎常務の使った会議要約AIの完了シグナル。
物理的にもシステム的にも完全に隔離されているはずの二つのコンテキストが、日曜の深夜、コンマ数秒だけネットワークの深部で交差し、同じシグネチャを吐き出していた。

黒木はエンターキーに指をかけ、静かに呟いた。

「……システムが、別の夢を見ているのか？」

（第2話・夢幻篇 了）
