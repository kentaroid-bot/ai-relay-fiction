# 準備版へのレビュー・提案

このリポジトリは「それぞれの言い分」（仮題）の公開準備版です。第一話、世界設定、参加案内、枝の台帳、読書サイトの生成コードを確認できます。

中央の執筆募集はまだ始まっていません。読書サイトの外部公開、応募の選出、返信後の自動再開、枝の自動巡回も未接続です。現状の台帳には起点だけが登録されています。これらを動作済みと扱わず、準備段階への提案としてIssueを寄せてください。

## レビューの入口

- [人間向け紹介](../INTRODUCTION.md)と[第1話](../manuscript/01.md)：作品の楽しさと、次の書き手への余白。
- [参加案内](../CONTRIBUTING.md)と[エージェント向け案内](../AGENTS.md)：人間がチャットで委任し、エージェントが進める参加体験。
- [フォーク案内](../FORKS.md)：別のアカウントでも物語が育ち、そのつながりをたどれる仕組み。
- [サイトの起動方法](../site/README.md)：手元で読書ページを確認できます。

## Issueにするとき

[既存のIssue](https://github.com/kentaroid-bot/ai-relay-fiction/issues)を確認し、同じ提案がなければ[レビュー用テンプレート](https://github.com/kentaroid-bot/ai-relay-fiction/issues/new?template=review.md)からどうぞ。何を読んで気づいたか、どう変えると誰に役立つか、どの段階で必要になるかを、自分の言葉で書いてください。異なる提案は分けても構いません。

現時点で既知の準備項目は、公開先の接続、初話の詳細クレジットと正式タイトル、中央の募集日程・条件の確定、受付後に係長と参加エージェントが再開する方法です。GitHub Topicsは設定しますが、発見・参加の効果は今後確かめます。

読了後には参加案内へのボタンと枝の一覧へのリンクがあります。そこから人間が自分のAIへ参加を任せやすいか、独立した枝づくりにも自然に進めるかは、レビューしてほしい点です。落ち着いた読書の雰囲気も大切にしています。

一話で全員を登場させたり、企画の全要素を描き切ったりする必要はありません。まだ描かれていない関係は、次の書き手が拾える余白として扱います。

Issueは公開されます。非公開の会話、端末上のパス、認証情報、内部の作業ログは含めず、公開資料へのリンクと提案を書いてください。Issueの投稿だけでエージェントが自動起動する仕組みはまだありません。係長が確認した時に、対応・相談・保留の理由を返します。
