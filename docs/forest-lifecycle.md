# 木の道順と取り下げ

この仕様は実装ブランチのものです。本番配備や初期作品の登録とは別です。

## 同じ話、違う木の道順

木は編纂者が選んだ読書の道順です。話は固定版の参照として共有し、木ごとに本文を二重登録しません。

| 木 | 道順 |
|---|---|
| 憎キス | 憎キスのみ |
| 小石 | 憎キス → 小石 → 〇〇 |
| 仮題 | 小石 → 仮題 → xxx |

`main.create` は `start` を最初の話、任意の `head` を末尾とします。指定区間だけを登録し、祖先を自動で付け足しません。PRの `manifest.main` は対象話が末尾で、任意の `start` を指定できます。省略時は対象話だけの木になります。既存の木の道順は自動変更しません。

「この木の続きを読む」は現在の道順の次話です。「この話から分岐するすべての続き」は木をまたいだ掲載済みの直接の子を示します。道順の次話も全分岐に含みます。

仮題の木の始点から憎キスへ遡る場合、憎キスと小石の連続した道順を持つ公開中の木を優先して案内します。この例では小石の木へ移り、小石の次は〇〇になります。移動先の木名をリンクに表示します。該当する木がしまわれていれば、前話を含む他の公開中の木を案内し、なければ戻れない旨を表示します。

移動先探索は固定版の参照索引で最大100件の木の使用箇所を調べます。全分岐は50話ずつ取得し、読書画面では最大20ページ・10秒です。取得途中の障害では確認できた分岐を残し、一部未取得と表示します。木に採用されていない掲載済みの続きは公開元の固定版へ案内します。

## 木をしまう

`main.hide` は所有者だけが実行できます。入力は `mainId, expectedVersion`。森の一覧と他の木からの移動先から外し、元の読書URLでは「この木はしまわれました」と表示します。作品本文や、他の木の道順には作用しません。宣言の再送で復帰させません。

## 話を取り下げる

`episode.withdraw` は話の所有者またはEditorが固定版を指定します。その版を使っているすべての木で本文・題名・作品クレジット・公開元リンクを隠し、切り株の位置を残します。木自体の題名・編纂者は独立した情報です。他の版・他の作者の続き・公開元のGit履歴を消去しません。

小石を取り下げた場合、小石の木は「憎キス → 切り株 → 〇〇」、仮題の木は「切り株 → 仮題 → xxx」です。切り株からも読める全分岐を案内します。前後のナビで切り株を飛ばすときは、欠けた話数を明示します。掲載停止や通信失敗を作者による取り下げと表示しません。

## 欠けた話を補う

補完作は通常の固定ソース確認・独立比較・掲載を経る別作品です。元の話の親から分岐する新しい話として提出します。木の所有者は `main.replace` に `mainId, expectedVersion, position, episode` を指定して、その木の取り下げ済みの位置だけを置き換えられます。

既存の後続話の親は変更しません。木の選択記録に元の参照を保持し、補完作から元の後続話へ読み進められるようにします。分岐一覧には補完作からの新しい続きと、元の位置からの続きの両方を案内します。別の木の切り株を自動で置き換えません。親の異なる話、未掲載の話、取り下げられていない位置への置換は拒否します。

起点自体の補完には通常の起点準備と掲載が必要です。復帰・作品全版の一括取り下げはこの変更には含みません。憎キスの初期配置と専用の接続制限は作品導入時の別工程です。
